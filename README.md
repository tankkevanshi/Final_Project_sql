# 🎓 Advanced Student Management System — MySQL

> **A relational database project demonstrating advanced SQL, database design, data analysis, complex joins, subqueries, window functions, conditional logic, schema modification, and SQL debugging using MySQL.**

---

## 📌 Project Overview

The **Student Management System** is a relational database project developed using **MySQL** to manage and analyze academic information across students, courses, instructors, departments, and enrollments.

The project is designed to demonstrate how SQL can be used not only for basic data storage and retrieval, but also for **relational data analysis, business-style reporting, complex query construction, and database problem solving**.

### Core Entities

```text
Students
   │
   │
   ▼
Enrollments ─────────► Courses
                          │
                          ▼
                    Departments
                          │
                          ▼
                     Instructors
```

The database contains **5 interconnected tables**:

* `Students`
* `Courses`
* `Instructors`
* `Enrollments`
* `Departments`

---

# 🚀 Project Objectives

The major objectives of this project are:

* Design a structured relational database.
* Store and manage student information.
* Manage courses and departments.
* Track student course enrollments.
* Maintain instructor information.
* Perform multi-table relational analysis.
* Apply aggregate and analytical functions.
* Implement subqueries and nested queries.
* Use window functions for analytical calculations.
* Apply conditional logic using `CASE`.
* Perform schema modifications using `ALTER TABLE`.
* Practice SQL debugging and error resolution.
* Build a foundation for real-world data analysis.
